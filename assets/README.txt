Battle Blocks assets

png/playscreen.png: source tile sheet for the game and menu, including
large lettering and next-piece previews.
png/titlescreen.png: approved 640x480, 16-color isometric metropolis splash.
It is reproduced by scripts/render_splash.py using integer pixel geometry.
png/cyberpunk-background.png: indexed 64x64 Microchip repeat. Its native
wallpaper uses muted navy traces and neutral blue contacts; foreground neon
colors stay independent.
png/foundry-background.png: generated indexed 64x64 riveted steel repeat.

font/16x16_sm_ascii.png: source font used to generate FONTMAP.DAT.
palette/cx16palette.png: X16 palette used to encode the gameplay tile sheet.
palette/light.json and cyberpunk.json: source palettes.
palette/arcade.json, foundry.json, synthwave.json, and matrix.json: generated sixteen-color banner palettes.

scripts/: production converters, builders, and their native drawing helpers.
bitmap_font.py supplies the small HUD/banner font and tetromino shapes.
hud_art.py and nameplate_art.py draw the approved cards and player banners.
computer_art.py draws the robotic computer faces using each theme's palette.
build_menu_title.py reuses splash lettering for the transparent MENU.DAT logo
and its rainbow Commander X16 variant MENU-A.DAT, sharing menu_title_generated.h.
build_foundry.py creates the Commander X16, Cyberpunk and Foundry scene palettes, neutral blue-framed Commander X16
surfaces, and Foundry surfaces and wallpaper. Commander X16 and Foundry palette
entries each alias exactly sixteen RGB colors;
Foundry blocks share steel shadows and ivory bevel highlights.
build_hud.py generates HUD.DAT, HUD-A.DAT, and HUD-F.DAT, compositing each
theme's playfield rim into the statistics cards that share its map cells.
build_synthwave.py generates SYNTH.DAT and SYNTHP.DAT: neon frames
and a fixed sixteen-color palette with a flat dark background.
HUD-S.DAT and NAME-S/NAME-SX.DAT use matching cards and robotic computer faces.
The HUD stores each five-pixel font row as one byte to preserve low RAM.
The build writes generated tile atlases and C headers into src/.

sound/: bundled music, effects and their generated headers; see README.txt
inside that directory. Refresh them with make import-sounds.

Approved banner reference crops used by emulator tests live separately in
tests/fixtures/banners/. Tests do not write screenshots into assets/.

Matrix assets are generated by build_matrix.py: MATRIX.DAT frames and grids,
MATRIXP.DAT fixed sixteen-color palette, and MATBG.DAT sparse code wallpaper.
HUD-M.DAT and NAME-M.DAT/NAME-MX.DAT share the native HUD and banner layouts.
All themes share the original startup splash, displayed once per launch.
