# Documentation images

`screenshots/` contains native emulator captures of the current game. The README,
website builder, and browser checks use these images. Refresh them after visual
changes with `make` followed by `python3 tools/capture_screenshots.py`.
`menu.png` is the default Commander X16 main menu.

The robotic computer faces used by the game are generated by
`assets/scripts/computer_art.py`.

The gameplay GIFs live in `img/`. Refresh both with `make demo`.
